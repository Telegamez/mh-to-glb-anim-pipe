Make a package — on this machine

Unreal and Blender make the model; the local stack photographs it; Compress makes the ktx2 build.

Publish — in the Publisher

A finished package goes to panda through the Publisher (Start-Publisher.ps1, port 7311): it reads the character's id from the package's character.json, publishes the ktx2 build as a version, takes it live and removes old versions, every call with a reason. Beta is reached by promotion from panda, on the platform's admin page, never from here.
